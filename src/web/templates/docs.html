📖 Kullanım Belgeleri

Kurulumdan ileri düzey kullanıma kadar, Oh My Coder'ın tüm yeteneklerine hızla hakim olun.

Kurulum

Tek komutla Oh My Coder kurulumu:

pip install oh-my-coder

Veya kaynaktan kurulum:

git clone https://github.com/VOBC/oh-my-coder.git cd oh-my-coder pip install -e .
💡
Python 3.9+ gerekir. Sanal ortam kullanmanız önerilir: python -m venv .venv && source .venv/bin/activate

İlk Görev

Kurulum tamamlandıktan sonra Web arayüzünü başlatın:

omc server start

Tarayıcıda http://localhost:8080 adresini açın ve görev giriş kutusunda ihtiyacınızı tanımlayın.

Veya CLI ile doğrudan çalıştırın:

omc run "Bir kullanıcı kimlik doğrulama sistemi uygula"

API Anahtarı Yapılandırma

Oh My Coder varsayılan olarak DeepSeek ücretsiz kotasını kullanır, sıfır maliyetle kullanılabilir. API Anahtarı yapılandırmanın iki yolu var:

Yöntem 1: Web arayüzü yapılandırması

Ayarlar sayfasına gidin, API Keys sekmesinde Anahtarınızı girin.

Yöntem 2: Komut satırı yapılandırması

omc config set -k DEEPSEEK_API_KEY -v sk-your-key-here
🎉
DeepSeek günde 40 milyon token ücretsiz kota sağlar, çoğu bireysel kullanım için fazlasıyla yeterli!

  • Ollama Yerel Modeller — Sıfır maliyet, gizlilik koruması

Agent Sistemi

Her Agent bir alana odaklanır, gerçek bir mühendislik ekibinin üyesi gibi:

  1. 🔍 Explorer
    Proje yapısını keşfeder, kod tabanını anlar, bağlam toplar
  2. 🧠 Analyst
    Gereksinimleri analiz eder, görevleri ayrıştırır, yürütme planı hazırlar
  3. 🏗️ Architect
    Mimari çözüm tasarlar, teknoloji seçimi ve kod yapısını belirler
  4. 💻 Executor
    Kod yazar, işlevleri uygular, dosyaları düzenler
  5. ✅ Verifier
    Sonuçları doğrular, testleri çalıştırır, kod kalitesini onaylar
  6. 🐛 Debugger
    Bug'ları bulur, hataları analiz eder, sorunları düzeltir
  7. 🔎 CodeReviewer
    Kod incelemesi yapar, potansiyel sorunları bulur, iyileştirme önerileri sunar
  8. 🛡️ Security
    Güvenlik taraması yapar, zafiyetleri tespit eder, uyumluluğu doğrular

Model Yönlendirme

Oh My Coder, görev karmaşıklığına göre otomatik olarak en uygun modele yönlendirir:

🧠
LOW → Basit sorgular (dosya listesi, biçimlendirme)
MEDIUM → Olağan görevler (özellik uygulama, hata düzeltme)
HIGH → Karmaşık görevler (mimari tasarım, uçtan uca geliştirme)

Akıllı yönlendirme, görev kalitesini koruyarak Token tüketimini %30-50 azaltabilir.

CLI Kullanımı

# Web arayüzünü başlat omc server start # Görevi yürüt omc run "Görev açıklaması" # Model ve iş akışı belirt omc run --model deepseek --workflow build "Görev açıklaması" # Geçmişi görüntüle omc history # Yapılandırmayı görüntüle omc config list # Kod incelemesi omc review

Eklenti Sistemi

Oh My Coder eklenti genişletmesini destekler, özel Agent, Skill ve Hook kaydedebilirsiniz.

# Eklenti oluştur from src.plugins import register, PluginBase, PluginMetadata @register class MyPlugin(PluginBase): @property def metadata(self): return PluginMetadata( name="my-plugin", version="0.1.0", description="Özel eklentim", ) def on_load(self): print("Eklenti yüklendi") def register_skills(self): return {"greet": lambda: "Hello!"}

Yerel Modeller (Ollama)

Yerel modelleri Ollama ile çalıştırın, sıfır maliyetli ve tamamen özel:

  1. Ollama'yı kurun
    ollama.ai adresine giderek indirip kurun
  2. Model indirin
    ollama pull qwen2:7b — 7B parametreli model önerilir
  3. Servisi başlatın
    ollama serve — Oh My Coder otomatik olarak algılar
⚠️
Yerel modeller en az 8GB bellek gerektirir. 7B modeli yaklaşık 4GB VRAM, 13B yaklaşık 8GB gerektirir.
